# Rimbook integrated workflow validation

This checkpoint validates the current main application as one integrated codebase.

Run the repository validation workflow on pull requests:
- Node syntax checks for every root JavaScript module.
- Manifest JSON validation.
- Storage integrity recovery tests.
- UI behavior tests covering notebook consolidation, retired habits navigation, worker profiles, daily attendance, payroll reversals, audio recording/playback, full attachment backups, ZIP backup/restore and direct transfer.

This is a code-validation checkpoint only. It is not a separate application build or APK release.
